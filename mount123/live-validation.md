## 发现并修复的问题

首次进入大 ZIP 返回 EIO，日志指向非 UTF-8 文件名。独立检查发现 797 个条目均使用可解码为 GB18030 的旧编码，没有危险路径。补齐文件名解码后，原归档目录读取和成员完整内容比对通过。

新增回归测试从 ZIP 字节经过解析到 FUSE Lookup，覆盖旧中文编码、CP437 以及带 CRC 的 Unicode Path 扩展字段。仅改变显示路径；原始 ZIP 名称保留供内容读取与缓存键使用，路径安全校验仍在解码后执行。

本次验证覆盖普通文件、单卷非加密 ZIP 的 Store/Deflate 成员；不是对全部账户文件、全部编码、加密或分卷归档的兼容性承诺。未向网盘上传、修改或删除文件。验收结束后卸载临时挂载点。
