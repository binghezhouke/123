# 10 — 显示预取与缓存诊断信息

**What to build:** 提供按需打开的诊断视图，帮助区分下载、解压和缓存导致的浏览延迟。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Publication:** https://github.com/binghezhouke/123/issues/11；标签待补充（GitHub 403）。

- [ ] 可查看当前预取队列、并发请求数、缓存占用和命中情况，并可重置统计。
- [ ] 请求耗时与服务器解压耗时分开呈现；无法测量的部分标为未知，不伪报为实测值。
- [ ] 诊断默认收起，关闭时不会持续产生大量额外请求或日志。
- [ ] 不展示带凭据的下载直链或解密密码；用冷缓存、热缓存及失败请求验证统计。
