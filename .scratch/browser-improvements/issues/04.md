# 04 — 恢复图片浏览进度

**What to build:** 普通目录和压缩包记录最后浏览图片，再次打开时可回到上次位置。

**Blocked by:** 02 — 普通目录图片使用统一查看器

**Status:** ready-for-agent

**Publication:** https://github.com/binghezhouke/123/issues/5；标签待补充（GitHub 403）。

- [ ] 关闭后重新进入同一目录或压缩包，可以继续上次浏览的图片。
- [ ] 显式点击某张图片时优先打开所点击图片，不被历史进度覆盖。
- [ ] 按稳定成员身份保存位置；成员删除、压缩包版本变化时安全回退并说明原因。
- [ ] 不同目录和压缩包的进度互不覆盖，存储不可用时仍能正常浏览。
