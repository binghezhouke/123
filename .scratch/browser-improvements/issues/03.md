# 03 — 恢复目录浏览位置

**What to build:** 从文件或下一级目录返回时，恢复此前目录的已加载列表、滚动位置和选中文件。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Publication:** https://github.com/binghezhouke/123/issues/4；标签待补充（GitHub 403）。

- [ ] 浏览器后退到目录时恢复已加载分页及滚动位置，无重复条目。
- [ ] 每个目录独立记录位置；恢复时保持原排序、筛选条件一致。
- [ ] 原文件已删除、目录变化或缓存失效时安全回退，页面仍可继续分页和导航。
- [ ] 验证多页目录、连续进入多个子目录再返回的流程。
