# 02 — 普通目录图片使用统一查看器

**What to build:** 普通目录图片使用与压缩包一致的查看体验，支持全屏、缩放拖动、连续浏览和方向预取。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Publication:** https://github.com/binghezhouke/123/issues/3；标签待补充（GitHub 403）。

- [ ] 普通图片可在统一查看器中全屏、缩放和拖动，桌面与触屏均可操作。
- [ ] 前后切换遵循目录图片顺序；到已加载分页边界时可继续加载并浏览，无重复或跳图。
- [ ] 按浏览方向持续预取默认 9 张，复用已加载内容；反向浏览调整预取窗口。
- [ ] 关闭或切换图片时清理无用请求与资源；加载失败可重试，不妨碍继续浏览。
