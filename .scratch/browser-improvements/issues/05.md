# 05 — 大图片解压改用临时文件

**What to build:** 大图片解压与响应改用临时文件，降低并发浏览时的服务器内存峰值，同时维持图片完整性校验。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Publication:** https://github.com/binghezhouke/123/issues/6；标签待补充（GitHub 403）。

- [ ] 大图片可完整预览，读取和解压采用有界缓冲，不将完整输出再次复制到内存。
- [ ] 在对外提供图片前完成适用的完整性校验；损坏或密码错误显示可理解的错误。
- [ ] 响应结束、客户端中断或解压失败后清理临时文件；不同会话的受密码保护内容相互隔离。
- [ ] 以并发大图片用例记录内存峰值，证明内存占用不会随全部解压输出大小线性增加；小图片预览保持正常。
