# 08 — 图片缩略图导航与序号跳转

**What to build:** 统一查看器提供可收起的缩略图栏，以及按序号直接跳转到图片的能力。

**Blocked by:** 02 — 普通目录图片使用统一查看器

**Status:** ready-for-agent

**Publication:** https://github.com/binghezhouke/123/issues/9；标签待补充（GitHub 403）。

- [ ] 普通目录和压缩包均可显示缩略图栏，当前图片高亮并可点击切换。
- [ ] 仅为可见及邻近区域按需准备缩略图，首次打开不会下载整个目录的原图；缓存有界。
- [ ] 输入有效序号可跳转对应图片，跨分页时按需加载；无效序号明确提示。
- [ ] 收起栏、关闭查看器及快速切换时正确取消无用任务、释放资源。
