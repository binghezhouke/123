# 01 — 修复压缩包收藏定位

**What to build:** 打开压缩包成员收藏时校验压缩包版本与成员路径，防止压缩包更新后按旧序号打开其他文件。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Publication:** https://github.com/binghezhouke/123/issues/2；标签待补充（GitHub 403）。

- [ ] 未变化的压缩包收藏可直接定位到原成员，并保留收藏颜色。
- [ ] 成员重排、删除或压缩包替换后，不会静默打开其他成员；失效时明确提示并提供返回目录入口。
- [ ] 兼容已有收藏数据；无法确认目标时提示重新定位，不丢弃原收藏。
- [ ] 覆盖版本变化、同名不同路径和旧格式收藏的回归验证。
