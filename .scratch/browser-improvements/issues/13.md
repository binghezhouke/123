# 13 — 嵌套压缩包按需后台准备

**What to build:** 用户手动启动内层压缩包准备；后台解压到磁盘，完成后进入现有压缩包浏览，并复用受限磁盘缓存。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Publication:** https://github.com/binghezhouke/123/issues/14；标签待补充（GitHub 403）。

- [ ] 仅由明确的准备操作启动任务；页面展示阶段、已处理字节及取消入口，未知总量时不伪造百分比。
- [ ] 支持当前可读取外层压缩包中的内层压缩包，按需请求密码；不支持的格式、缺卷或磁盘不足明确提示。
- [ ] 准备使用有界内存与磁盘暂存；刷新页面可重新获取仍运行任务的状态，取消或失败清理不完整输出。
- [ ] 完成完整性校验后可浏览内层目录及预览支持的成员；相同外层版本和成员可复用准备结果。
